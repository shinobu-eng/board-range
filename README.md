# board-range — ポーカーGTO学習ツール

ボード×レンジのGTO戦略を「全アクション分布の色帯（色覚安全）」で表示する個人学習ツール。

- プリフロップGTO（3bet/コール/フォールド色分け・Pio 100bb）
- フロップGTO（curated韓国スポット＋**6-max 100bb BTN-BB は全1755フロップ網羅**）
- 色覚安全配色（赤緑ペア不使用・青×オレンジ×紫）
- 1755網羅データは `data/` から遅延読み込み（GitHub Pages配信）

公開URL: https://shinobu-eng.github.io/board-range/
